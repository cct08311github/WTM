Personal fork of WalkingTec MVVM (WTM), a .NET rapid-development framework. Active branch: `dotnet10`.
When priorities conflict: **Compatibility → Security → Quality → Performance**.

## Two remotes, one source of truth

- `origin` = Gitea `mac-mini.tailde842d.ts.net/chiu0831/WTM.git`. NuGet publishes to its registry (`/api/packages/chiu0831/nuget`), and `dotnet restore` fails with a misleading NuGet error until that private source is registered — `docs/getting-started.md`, `docs/gitea-packages.md`.
- `github` = `cct08311github/WTM`: a **sanitized daily mirror** generated by `.sync/` (`.sync/README.md` is the authoritative description). Never branch, merge, or commit there. Dependabot PRs and Security-tab alerts raised on the mirror are triaged with `/sync-dependabot` and `/sync-github-security`, fixed **on Gitea**, and reach the mirror on the next sync.

## CI red does not mean failed

`actions/upload-artifact@v4` is incompatible with the local Gitea Actions API, so `build-and-test`, `e2e`, `regression` and `integration` jobs report `conclusion: failure` even when every test passed (#11). Judge a run by reading its log, never by the badge:

- .NET → `Test Run Successful`
- e2e → `FAIL: 0` **and** `ERROR: 0` in the `Total: N | PASS: n | FAIL: n | ERROR: n | SKIP: n` summary line

**Never match a hardcoded `PASS: N`.** N legitimately differs between the `e2e-test.yml` matrix's `baseline` and `killswitch` legs (#681) and changes whenever `TC_REGISTRY` in `test/e2e/wtm_e2e_tests.py` grows. Workaround SOP → `docs/ci-operations.md`.

## Red lines

- Never bypass the VM layer to reach `DataContext` from a controller
- New functionality is **opt-in**; never silently change default behaviour. A breaking change needs a `CHANGELOG.md` entry, a migration path, and a minor version bump
- Never delete a `<PackageReference>` to silence NU1510 — several exist only to override a vulnerable transitive dependency (`.claude/rules/dependency-management.md`)
- **A commit message, PR body, or CHANGELOG entry may not claim more than the same change's entry in `docs/production-readiness.md`.** Four claims shipped in 2026-07 that the code did not support ("default-OFF byte-identical", "fingerprint enforced at the engine boundary", "matches legacy `return false`", "override the hook in a derived controller"); `production-readiness.md` described the same work honestly throughout. A claim of completeness — "no remaining exit", "all sinks covered" — additionally requires the command that proves it, run against the whole tree and not just `src/` (#835)
